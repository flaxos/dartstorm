DARTSTORM: Elemental Arena  (version @VERSION@, Windows x86_64)
================================================================

PLAY
  1. Extract the entire zip folder somewhere convenient (e.g. Desktop or Games).
  2. Double-click DARTSTORM.exe to play!

  Note: Because this is an indie unsigned build, Windows SmartScreen may show
  "Windows protected your PC" on first launch. Click "More info" -> "Run anyway".

CONTROLS
  * Keyboard & Mouse: WASD move, Mouse aim, Left-Click fire/swing, Right-Click ADS,
    Shift sprint, Space jump, R reload, G grenade, F interact, 1-5 weapons, Tab scoreboard, Esc pause.
  * Controllers: Plug in any Xbox/PlayStation/generic controller anytime — A presses, B goes back.

YOUR SETTINGS & SAVES
  Saved in %APPDATA%\dartstorm\ (delete that folder to start fresh).

NEEDS
  A 64-bit Windows 10 or Windows 11 PC. Uses Vulkan graphics (or falls back to
  OpenGL automatically if run with --rendering-driver opengl3).

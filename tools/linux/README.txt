DARTSTORM: Elemental Arena  (version @VERSION@, Linux x86_64)
================================================================

PLAY
  Double-click DARTSTORM.x86_64.

  If double-clicking doesn't start it, do ONE of these:
    * Run ./install-shortcut.sh once (double-click it and choose "Run", or run it in a terminal).
      DARTSTORM then appears in your applications menu, and on the desktop if you have one.
    * Or open a terminal in this folder and type:  ./DARTSTORM.x86_64

CONTROLLERS
  Plug a controller in at any time (before or during the game). A presses, B goes back.

YOUR SETTINGS
  Saved in ~/.local/share/dartstorm/ (delete that folder to start fresh).

REMOVE
  Run ./install-shortcut.sh --remove, then delete this folder.

NEEDS
  A 64-bit Linux PC. It uses Vulkan graphics, and switches to OpenGL by itself on older PCs.

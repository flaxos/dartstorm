# Assets and Licences

Everything in DARTSTORM is **original to this project** (generated via Godot scripts, Python procedural texture pipelines, or bespoke project artwork), except one open-source font:

| Asset Category | Location | Provenance & Notes |
|---|---|---|
| **3D Models (Blasters, Hero, Props)** | `assets/models/` (`blasters/`, `characters/`, `props/`) | Original stylized `.glb` / `.tscn` assets generated by the pure-Python parametric sculptor pipeline (`tools/sculpt/mesh_sculpt.py`, `sculpt_hero.py`, `sculpt_blasters.py`, `sculpt_props.py` + Godot headless packers `pack_*_scene*.gd`), paired with hybrid procedural models in `scripts/effects/blaster_model.gd` (including the **Foam Bat** & animated Chainstorm dart belt), `character_model.gd`, and `scripts/arena/*.gd`. See [`assets/models/README.md`](models/README.md). |
| **Custom Shaders (12)** | `assets/materials/*.gdshader` | Original Godot 4.4 spatial shaders: `dartstorm_toon`, `toon_outline`, `cloth_flag`, `blaster_skin`, `foam_dart`, `foam_shield`, `foam_splat`, `lava_foam`, `lawn`, `stylized_water`, `toon_character`, and `toy_wood`. |
| **Procedural PBR & Arena Textures** | `assets/textures/pbr/`, `assets/textures/arenas/` | Seamless albedo, tangent-space normal, packed ORM, and micro-detail PNGs generated by `tools/generate_pbr_textures.py` and `tools/generate_arena_pbr_textures.py`. |
| **Blaster Skin Vector Patterns** | `assets/textures/skins/` | 8 seamless 1024×1024 black-and-white 2D graphic patterns generated via `tools/generate_skins.py` for the triplanar `blaster_skin.gdshader` pipeline. |
| **Cover Art, App Icons & Boot Splash** | `assets/branding/`, `docs/media/`, `icon.svg` | Original DARTSTORM v1.0.0 key art (`docs/media/cover_art.jpg`), boot splash (`assets/branding/boot_splash.png`), rounded app icons (`icon_512.png`, `icon_192.png`, Android adaptive `icon_adaptive_fg_432.png` / `icon_adaptive_bg_432.png`, Windows multi-resolution `dartstorm.ico`), vector fallback `icon.svg`, and Forward+ in-game screenshots (`docs/media/shot_*.png`). Note: `docs/*` is excluded from game exports so screenshots and full-res cover art add zero size to release builds. |
| **Sound Effects & Music** | `scripts/core/sfx.gd` | 100% procedurally synthesised at startup (blaster launches, `bat_swing` / `bat_bonk`, elemental FX, announcer/UI cues, and two worker-thread-rendered chiptune music loops). |
| **Display Font** | `assets/fonts/LilitaOne-Regular.ttf` | **Lilita One**, **SIL Open Font License 1.1**, from Google Fonts (`github.com/google/fonts`, `ofl/lilitaone`), used unmodified. Copyright and licence travel with the font in [`assets/fonts/OFL.txt`](fonts/OFL.txt) and are bundled as `FONT-LICENSE.txt` in standalone desktop releases. Fallback: Godot's built-in font. |

DARTSTORM branding is 100% original. There are no trademarked blaster names, logos, or real-world firearm designs anywhere in the project.

## Adding External Assets

If you ever add a third-party file, place it under `assets/<type>/` and add a row above with:
**file, author, source URL, licence** (CC0 / CC-BY / MIT / OFL, etc.), plus any attribution the licence requires.
Never add assets with unclear or "non-commercial only" licences.
